# 博客结构对比原型

待回答的问题：参考图的顶部导航、插画欢迎区和开放文章列表是否适合博客首页？当前方向为 D，尚未应用到正式博客。

运行：`python3 prototype/structure-comparison/serve.py`

打开 http://127.0.0.1:4174/?variant=D 。底部按钮及左右方向键切换；原有首页、文章、分类路径不变，链接会保留方案参数。

- D 参考图方案：桌面顶部“文章 / 专题 / 归档 / 搜索”，第二张参考图的插画欢迎区，下方分隔线式近期文章列表，页脚左侧 GitHub 和 RSS 圆形图标。默认5条，用 `count=4` 或底部4/5条按钮比较密度。只有2篇真实文章，其余为明确标注的排版示例；示例不作为已发布文章，也不创建无效链接。

- A 精简三栏：保留侧栏与卡片，删除重复更新和简介统计，保留专题与标签。
- B 专注双栏：保留侧栏，去掉辅助栏，开放式文章列表，正文内可展开目录。
- C 编辑式首页：桌面顶部导航，最新文章和欢迎语并排，其他文章在下方；手机纵向排列。
- original 当前版：现有页面原样对照。

原型直接读取 `_site` 现有构建，保持两篇真实文章及所有资源。无依赖、无数据保存、无后端写入。服务仅绑定127.0.0.1，按Ctrl+C停止。只有这个本地服务注入原型CSS/JS，正式Jekyll构建不包含切换器。

D 的文章底部将原有相关文章卡片和上一篇/下一篇合并为“相关文章推荐”列表。按文章路径去重、排除当前文章，最多5条；目前每篇只有1篇可推荐的真实文章，不补虚构条目。

文章右侧只保留目录，移除热门标签；正文底部的文章标签保持不变。

D 的手机首页使用浅灰底、独立欢迎卡片和文章卡片，两侧至少16px留白，卡片内边距20px、卡片间距14px；桌面仍为分隔线列表。

手机欢迎卡片沿用PC的同一幅插图，完整显示，保持原色和不透明度，只按屏幕宽度缩放。

手机文章页的推荐区外缘及文字分别对齐文章主体外缘和正文，两侧留白一致；推荐列表无箭头。代码窗口左侧圆点使用Mac的红、黄、绿配色，手机与桌面一致。

PC推荐区也与正文左右边界对齐，保持标题、日期、摘要的列表结构，摘要自然换行，不延伸到右侧目录下方。

抛弃式实现。用户选定后，将原型保存到独立临时分支作为决策记录，再在正式模板中重新实现选中的布局。当前不提交，不发布。
