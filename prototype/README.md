# 技术博客视觉原型

用于比较 Chirpy 风格的博客配色与布局。原生 HTML/CSS/JavaScript，无需安装依赖，也不是最终 Jekyll 实现。

在仓库根目录运行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory prototype
```

打开 http://127.0.0.1:4173/ 。也可以直接打开 index.html。

- A：参考用户截图调整，白色侧栏、浅灰点阵背景、柔和阴影及少量浅蓝/薄荷/粉色点缀，保留 Chirpy 布局。
- B：顶部导航与杂志式卡片，暖色横幅。
- C：浅绿侧栏与单栏手记，更重视阅读密度。
- 底部切换器或左右方向键切换，URL 的 `?variant=A|B|C` 保存布局选择。
- 支持文章详情、目录滚动、分类、标签、归档、即时搜索和深浅色切换；窄屏使用折叠菜单。
- 文章、日期、作者介绍均为演示占位，不是用户真实写作。
- 状态仅在内存中，无后端、统计或数据存储。尚未发布 GitHub Pages。

待用户确认配色与布局后，在正式 Chirpy 项目中重新实现对应样式。
